# FoxFabric Template

v1.0.0\
2026-11-11

Template for creating other FoxFabric addons.

Contains a sample class `Adder` and demo on its usage.


## Example

```gdscript
var adder := Adder.new()
var result := adder.add(2, 1)  
print(result) # 3.0
```


## Classes

- `Adder`: A node that adds numbers together.


## Requirements

Godot 4.7 or above


## Installation

Copy `addons/foxfabric_template` into your project's `addons/` folder.
